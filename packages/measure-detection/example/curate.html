Measure curation Choose a PDF.

Open a book (a PDF with one or more songs) or an existing document. The state of a book is saved on the server (dataset/curation/) and restored when the same PDF is opened again. Documents lists every document in dataset/documents; open one to correct it and save it in place.

Documents store only the song number and the show id. Titles and show names are never stored; choose the show in the header (a new book starts as a new show).

1. Split into songs. In the page overview, click a page to start a new song there; click the first page of a song to merge it into the previous one. Mark pages that are not songs (index, front matter) as skipped.

2. Detect and curate. Open a song, run the detector, then correct the boxes and values. Red boxes have low confidence, green boxes were edited or confirmed by you.

3. Export. Writes dataset/documents/<id>/ (score.pdf with the song's pages, measures.json, source.json with show id and song number) and adds the id to train.txt or val.txt.
